# Jump Cash — roadmap

- [x] Tipos de conta por usuário (jogador, afiliado, influencer, agente, admin)
- [x] Bloqueio de usuários (modos de bloqueio)
- [x] Suporte ao vivo (tickets + mensagens)
- [x] Notificações administrativas em tempo real
- [x] Alertas de movimentações suspeitas
- [x] Personalização do frontend (site_settings)
- [x] Modo bônus + valores fixos de aposta em game_settings

## Fase 2 — backend
- [ ] Server functions de suporte (usuário + admin)
- [ ] Notificações (criação automática em cadastro/depósito/saque/suporte)
- [ ] Alertas suspeitos (tentativa de acesso admin, padrões anormais)
- [ ] Bloqueio aplicado em login/aposta/depósito/saque
- [ ] Edição completa do usuário no painel admin
- [ ] Taxa de depósito aplicada; visão geral só com depósitos validados

## Fase 3 — frontend
- [ ] Rota /admin bloqueada para não-admin

- [ ] Central de notificações no admin (tempo real)
- [ ] Aba de personalização do site
- [ ] Perfil do usuário: código de indicação + dados completos
- [ ] Validações de CPF/nome no cadastro e no saque
